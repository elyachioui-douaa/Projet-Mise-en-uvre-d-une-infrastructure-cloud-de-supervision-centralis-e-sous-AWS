Ce dossier 'scripts' contient :

1. setup.sh
   - Met à jour le système
   - Installe Docker et Docker Compose
   - Prépare l'environnement pour déployer Zabbix

2. install_agent.sh
   - Installe l'agent Zabbix sur un client Linux
   - Configure l'IP du serveur Zabbix
   - Démarre et active le service agent

Note : Modifier les fichiers pour adapter les IP ou noms d'hôtes si nécessaire.
